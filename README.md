# my-website
Lee's Coffee Shop Website 

## Description 
Lee's Coffee Shop is a small independent coffee shop website created to provide customers with information about the coffee shop, its menu, services and contact details. 

## Purpose 
The purpose of this website is to provide customers with an easy way to learn about Lee's Coffee Shop, view the menu, make enquiries and find contact information.
