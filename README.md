Lee’s Coffee Shop Website 

1. Project Description 

Lee’s Coffee Shop is a website developed for a small independent coffee shop established in 2024 by three friends. The coffee shop provides customers with quality coffee, meals and friendly customer service in a relaxing neighbourhood environment. 

The website provides information about the business, its products, services, opening hours and contact details. It also allows visitors to explore the menu and make enquiries. 

2. Purpose and Objectives 

The purpose of this website is to create an online presence for Lee’s Coffee Shop and make information easily accessible to customers. 

The main objectives are to: 

•	Provide information about the coffee shop. 

•	Display the available food and beverages. 

•	Allow customers to explore the menu. 

•	Provide contact details and location information. 

•	Allow visitors to make enquiries. 

•	Create a user-friendly and responsive website. 

3. Target Audience 

The website is designed for: 

•	Students who want a comfortable place to enjoy coffee or meals. 

•	Working professionals looking for coffee and light meals. 

•	Local residents interested in visiting the coffee shop. 

•	Families and tourists looking for a welcoming coffee shop. 

4. Website Pages 

The website consists of five main pages: 

Home: Introduces Lee’s Coffee Shop and welcomes visitors. 

About Us: Provides information about the coffee shop, its background, mission and values. 

Services: Displays the available food and beverages, including coffee, breakfast, sandwiches and pastries. 

Enquiry: Allows visitors to submit questions about the menu, products and services. 

Contact Us: Provides the coffee shop’s contact details, opening hours and location. 

5. Technologies Used 

•	HTML5 – Used to create the structure and content of the website. 

•	CSS3 – Used to style the website, including colours, layouts, typography and responsive design. 

•	JavaScript – Used to add interactive features and improve user interaction. 

•	GitHub – Used for source code management and version control. 

•	GitHub Pages – Planned platform for publishing the website. 

6. Website Features 

The website includes the following features: 

•	Navigation menu to move between website pages. 

•	Responsive layouts for different screen sizes. 

•	Coffee shop menu displaying available products and prices. 

•	Responsive images. 

•	Hover effects and CSS animations. 

•	FAQ accordion that allows visitors to expand and read answers. 

•	Tabs for displaying the coffee shop’s story, mission and values. 

•	Image gallery with a lightbox that allows visitors to view images. 

•	Menu search and filtering functionality, where implemented. 

•	Enquiry form with HTML5 validation.
